# Security and Safety

This repository is a synthetic benchmark for studying monitoring
representations, calibration, escalation routing, and analyst workload.

It does not contain real user data, deployment logs, operational abuse traces,
or operational misuse instructions. The scenarios are abstract feature-level
probes designed to evaluate monitoring failure modes.

Do not use this benchmark as a production misuse detector without external
validation, domain-specific review, governance, and operational safety checks.
